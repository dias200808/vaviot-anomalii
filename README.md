# Аномалии потребления воды

Тестовое задание «Вавиот Азия» — Data Operations.
Автор: **Диас Ахметбек** · Telegram [@akhmetbekdi](https://t.me/akhmetbekdi)

Из накопительных показаний 3 000 приборов учёта воды (01.10.2025 – 01.10.2026) считается суточное потребление и ищутся аномалии: отрицательный расход, всплески, нереальные значения, утечки, нулевое потребление, ступеньки, связь с событиями «магнит».

## Как запустить

```bash
pip install -r requirements.txt
# положить pokazaniya.csv, pribory.csv, sobytiya.csv в папку data/
jupyter notebook anomalii_vody.ipynb   # Run All, ~1 минута
```

Все пороги вынесены в один блок `ПОРОГИ` в начале ноутбука — их можно поменять и перезапустить.
Файл `anomalii_vody.py` — тот же ноутбук в текстовом виде (удобно смотреть diff).

## Структура

| Файл | Что это |
|---|---|
| `anomalii_vody.ipynb` | весь расчёт с пояснениями и графиками |
| `results/na_proverku.csv` | приборы для выезда, отсортированы по баллу риска, с причинами |
| `results/v_tehpodderzhku.csv` | приборы с ошибками данных (не вода) |
| `otvety.md` | краткие ответы по пунктам 1–8 |

Исходные данные в репозиторий не выкладываются.

## Главное

* **Битовая ошибка 327.68 м³** (= 2¹⁵ × 0.01 м³): 347 скачков у 56 приборов — **все типа AQUA2**. Там же сдвиг запятой ×10 и показания в миллионы м³. Это ошибка прошивки/канала, а не вода.
* **Магнит** в целом не связан с падением расхода: события взлетели до 19 000 в сентябре 2026 без изменения потребления, а доля приборов с магнитом зависит от базовой станции (BS-09 — 56%, BS-07 — 7%). Адресно найдены 3 прибора, у которых при магните расход падает > 5 раз.
* **Утечки:** 155 приборов ≥ 90 суток без единого нулевого дня с «полом» ≥ 50 л/сут, у 41 это продолжается сейчас.
* **Остановившиеся счётчики:** 263 прибора потребляли, потом ≥ 30 суток показывают ровно 0, хотя продолжают выходить на связь.
